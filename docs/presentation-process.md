### 원리를 시각화한 구체적인 보완

- Codex 5·8·9장: 픽셀 배경 분포 개념, 같은 ROI의 실제 전경→열림→닫힘과 정확한 5×5 커널, 실제 윤곽선·bbox·모멘트 중심을 연결했다. 실제 f449 사례의 bbox `(566,243,30,94)`, 면적 `1646.5`, 정수 중심 `(581,287)`과 상자 중심 `(581,290)`의 차이를 설명한다.
- Codex 10·12·13·18장: 거리 게이트 안팎 후보, Tracker 보존 수명과 평가 10프레임 규칙의 별도 시간축, 감지 병합의 모호성, 평가 IoU의 교집합·합집합을 도식화했다.
- Codex 14·15·21·28장: 방향·샘플 쌍·비트·XOR/Hamming, 비율 필터·중복 제거, 실제 겹침 전후 ID, 관측 한계→개선 가설→검증 방법을 연결했다.
- Work v2 9·11·12·14장: L형 형상의 면적 중심과 상자 중심, 같은 좌표의 후보 연결과 Greedy 비용 `1+5=6`/대안 `2+2=4`, 5×5 밝기 패치와 독립적인 4비트 XOR를 그렸다. 모두 설명용 예시로 표시했다.
- Work v2 6·21·23장: 기존 GUI 검증 키 순서 `p/s/s/p/s/q`와 정지 f404·재개 f449를 노트에 연결했다. 실제 겹침 원본 f497/f505/f509와 관측 CSV의 bbox/ID를 대조했고 미관측 대상에 임의 ID를 붙이지 않았다. 조명 비교는 Wallflower LightSwitch의 `illumination-02`, 기준 f1853, 4Hz와 `17/26/2`프레임=`4.25/6.5/0.5`초를 명시했다.

### 제작 도구와 호환성 문제 처리

PPTX에는 이미지뿐 아니라 편집 가능한 도형·차트·표·텍스트와 발표자 노트를 넣었다. 임시 제작 프로그램과 캡처는 로컬 `tmp/`에서 관리했다. 이 PR은 최종 PPTX/PDF와 과정·검증 기록을 배포하며, 임시 빌드 환경 전체를 포함하거나 한 명령 재생성을 보장하지 않는다.

Codex 제작 중 이미지 경로 참조의 내장 실패는 PNG 바이트 내장으로, 범주형 시간축의 연결 오류는 수치형 원본 시각 축으로 고쳤다. 겹침·코드 잘림·의사코드와 실제 소스의 구분을 보완했다. 문서 속성의 Slides/Notes=0을 실제 파트 수에 맞추고 차트 워크북의 15자리 정밀도 차이는 표시 소수점 정리로 해결했다. 원시 CSV는 수정하지 않았다.

최종본은 구조 검사만으로 실제 PowerPoint 호환성을 단정하지 않았다. 정확한 해시의 PPTX 사본을 Microsoft PowerPoint에서 읽기 전용으로 열고 전 장 PNG를 내보냈으며, 별도 검토자가 그 결과를 확인했다. Codex PDF는 해당 최종 PPTX를 PowerPoint의 PDF 저장 형식으로 내보냈다.
