## 최종 검증과 실측

- 새 Windows 가상환경에서 잠금 파일로 설치하고 Python 3.11.4, OpenCV 4.14.0, NumPy 2.4.6을 확인했다. 자동 테스트 71개, 원본 26개 해시 검증, vtest 795프레임 전체 처리에 성공했다.
- 실제 GUI에서 일시정지·재개와 저장·종료를 확인했다. f404와 f449 PNG는 FFV1의 표시 프레임과 일치했다. 내장 카메라로 351프레임을 처리하고 종료했으며, 원본 카메라 영상은 저장하지 않았다. [앱 검증 기록](validation/issue-9.md)
- 실제 추적 관찰 30건, 학습률 9회·1,800프레임, ORB 5조건을 측정했다. 모든 관찰 입력은 원본 시간이 확인된 20–30초 클립이다. 조명 5건은 원본 4 Hz로 각각 25초이며 급변 3건과 점진적 변화 2건이다. [자료 출처](data_sources.md) · [실측 기록](../experiments/runs/)
- 기본 거리에서 추적 실패 사건은 단일 이동 9/10, 겹침 0/10, 정지 5/5, 조명 2/5였다. 겹침은 대상 20명 중 7명이 ID Switch 판정 가능했고, 거리 60픽셀에서 5건, 30픽셀에서 6건을 관찰했다. 독립 검토로 프레임 기록 3,479행과 앱 로그 24개를 재대조했다. [분석 보고서](analysis_report.md)
