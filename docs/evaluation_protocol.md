# 추적 평가 절차

[사건 계획](../experiments/event_plan.json)에 단독 이동 10건, 보행자 겹침 10건, 정지 후 재이동 5건, 실제 조명 변화 5건을 미리 선정했다. `start_frame`과 `end_frame`은 관찰 구간이며 `clip_start_frame`과 `clip_end_frame`은 전후 맥락과 모델 초기화를 포함한 입력 구간이다. 범위는 원본의 0번 기준이며 양 끝을 포함한다. `anchor_frame`은 물리적 사건이나 주요 상태를 찾기 위한 표식이다. 하나의 사건이 여러 입력에 있어도 같은 원본 사건은 한 번만 집계한다.

조명 평가의 입력 5개는 각각 원본 4 Hz의 100프레임, 25초다. 실제 조명 스위치를 조작한 급변 세 건과, 실제로 밝아지거나 어두워진 별개의 점진적 변화 두 건을 포함한다. 점진적 변화의 `anchor_frame`은 관찰 중인 변화를 찾기 위한 대표 프레임이다. 배경 밝기 변화와 대상의 가시성을 원본에서 확인한다.

## 원본 주석과 판정

1. 앱 출력과 대조하기 전에 원본에서 각 사건의 대상 인물과 가시성을 확인한다. CAVIAR는 XML의 객체 ID와 상자를 참고하고, vtest와 조명 자료는 원본을 보고 지정한 인물을 확인한다. 검토자는 겹침 전후에 옷과 진행 방향 등으로 인물을 구분한다. 단독 이동은 지정 구간에서 한 대상만 보행하는 경우를 뜻하며, 다른 사람이 화면에 정지해 있을 수 있다.
2. 각 원본 프레임과 대상에 대해 가시 여부, 가림 여부, 실제 관측된 추적 ID를 기록한다. 대상이 화면 밖에 있거나 가려져 몸의 50% 이상이 보이지 않으면 해당 대상 프레임을 제외한다. 원본만으로 가시성을 결정할 수 없으면 사유와 근거를 기록한다. 누락 또는 잘못된 ID의 연속 길이는 제외 프레임을 건너 이어 세지 않는다.
3. 현재 프레임에 새로 관측된 트랙을 원본 인물과 대조한다. 유지된 마지막 상자나 궤적은 해당 프레임의 관측으로 세지 않는다. 두 인물이 부분적으로 겹쳐도 각각의 관측을 구분할 수 있으면 따로 기록한다. 출력과 원본을 대응시킨 근거와 판단이 어려웠던 프레임을 남긴다.
4. **ID Switch**는 겹치기 전에 기준 ID를 확보한 인물이 겹친 뒤 연속 5개 이상 판정 가능한 프레임에서 다른 ID로 관측되면 기록한다. 연속 4프레임은 집계 기준에 미달하고, 5프레임에 이르면 한 번을 기록한다. 같은 할당이 이어지는 연속 구간은 한 번으로 세며, 두 사람의 ID가 서로 바뀌면 두 인물의 변화를 각각 센다. 기준 ID를 확인할 수 없거나 두 인물의 대응이 모호하면 확인된 근거와 함께 미판정으로 남긴다.
5. **추적 실패**는 가시성이 있는 대상이 연속 10프레임 이상 현재 관측되지 않을 때 기록한다. 연속 9프레임은 집계 기준에 미달하고, 10프레임에 이르면 한 번을 기록한다. 같은 누락이 이어지는 연속 구간은 한 번으로 세며, 이후 관측이 재개되면 다음 누락을 새로 판정한다. 가림이 49%인 프레임은 다른 제외 사유가 없으면 판정에 포함하고, 가림이 50%인 프레임은 제외한다. 정지 중에도 대상이 충분히 보이면 같은 기준을 적용한다. 추적기가 트랙을 내부적으로 보존하는 기간은 이 판정 기준과 별개다.
6. **겹침 외 조건의 지속 ID 변경**은 단독 이동, 정지, 조명 변화에서 별도 지표로 기록한다. 판정 가능하고 현재 관측된 연속 3프레임 이상에서 같은 ID를 확인해 기준을 정한다. 이후 다른 동일 ID가 판정 가능하고 현재 관측된 연속 5프레임 이상에서 나타나면 한 번으로 센다. 제외 또는 미관측 프레임은 연속 구간을 끊는다. 같은 후보 ID의 연속 구간은 한 번만 기록하고 겹침 ID Switch 집계와 분리한다.

## 집계와 기록

조건별 실패율은 추적 실패가 한 번 이상 확인된 유효 사건 수를 추적 실패 판정이 가능한 유효 사건 수로 나눈다. 겹침 ID Switch와 겹침 외 조건의 지속 ID 변경은 각각 합산한다. 평가 불가 사건은 유효 분모에서 제외하고 대상·원본 구간·제외 사유를 남긴다. 조건별로 계획 사건 수, 실제 평가한 유효 사건 수, 실패 사건 수, 실패 횟수, 해당 조건의 ID 변경 횟수, 제외 대상 프레임 수를 표시한다. 조건별 입력의 FPS가 다르면 10프레임이 나타내는 실제 시간이 달라질 수 있다.

[사건 기록 양식](../experiments/event_template.csv)에 원본 프레임 범위와 결과를 사건당 한 줄로 기록한다. 대상별 원본과 관측 ID, 가시성, 제외 사유, 연속 구간의 시작과 끝은 근거 기록에 보존한다. 실행 시에는 코드 커밋·변경 여부, 입력 SHA256, 소스와 클립의 프레임 대응, 학습률·추적 임계값·매칭 설정, 실행 명령 및 종료 상태를 함께 남긴다. 원본을 직접 대조한 판정과 자동 집계는 근거 경로로 연결한다.

배경 학습률 비교에는 동일한 입력 프레임과 초기화, 필터와 추적 설정을 쓰고 학습률만 3개 이상 바꾼다. 특징점 필수 비교는 동일 참조와 매칭 설정을 사용해 정면, 30° 회전, 60° 회전, 30% 가림, 50% 가림의 다섯 조건에서 수행한다. 회전은 이미지 평면 내에서 적용한다. 가림은 왼쪽 가장자리부터 직사각형 마스크를 씌우고, 가린 픽셀 수를 가림 전 대상 이미지의 전체 픽셀 수로 나눠 비율을 기록한다. 특징점 매칭률은 `good_matches / reference_keypoints`로 계산하고 `reference_keypoints`가 0이면 `None`으로 기록한다. 크기와 조명 변화는 선택 비교로 기록한다. 통제 변환 사진으로 측정한 특성은 촬영 조명 변화와 별도로 보고한다. 각 비교에서 정량 지표와 원시 기록을 보존한다.
