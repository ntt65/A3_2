# A3_2 영상 객체 추적과 타깃 재인식 한계 분석

OpenCV에서 움직이는 물체를 감지하고 중심점 거리로 ID를 부여했다. 별도로 ORB를 사용해 등록 물체를 프레임마다 찾았다. 추적 실패와 ID 변경은 실제 공개 촬영 자료에서 측정했으며, ORB의 회전·가림 효과는 같은 참조 사진의 통제 변환으로 비교했다. [미션 원문](A3_2_mission.pdf) · [앱 실행과 실험 재현](../README.md)

## 1. 실제 영상의 추적 성능

기본 설정은 MOG2 자동 학습률 `-1`, 열림·닫힘 커널 5, 최소 윤곽선 면적 500픽셀, 중심점 거리 제한 60픽셀, 연속 미관측 허용 5프레임이다. 클립마다 새 배경 모델과 추적기를 시작하고 원본의 모든 선택 프레임을 순서대로 처리했다. 앱 통합 커밋은 `adf856e`다. 최종 실험은 `5d40e40e423763c5e989f2766e02d9b50da3ac3f`의 깨끗한 작업 트리에서 Python 3.11.4, OpenCV 4.14.0, NumPy 2.4.6으로 실행했다. 원본·클립·대응표의 해시, 실행 명령, 구간과 설정을 보존했다. [자료 출처](data_sources.md) · [출처 목록](../experiments/data_sources.json) · [사건 계획](../experiments/event_plan.json) · [실행 메타데이터](../experiments/runs/event_metadata.json)

vtest의 겹침·정지 구간, CAVIAR의 보행·정지, Wallflower의 실제 조명 변화를 사용했다. 원본 샘플링 속도로 계산한 입력 클립의 길이는 24.44–25초다. CAVIAR의 참조 상자는 제공된 XML에서 가져왔다. vtest와 조명 자료는 원본의 주요 프레임에서 대상 상자를 지정하고 그 사이를 선형 보간했다. 평가 단계에서 현재 관측된 트랙만 참조 상자와 일대일 IoU 0.20 이상으로 자동 대응했다. 상자 보간과 대응 임계값은 집계에 영향을 줄 수 있다. 50% 이상 가림, 화면 밖 또는 원본에서 판정 불가인 대상 프레임을 제외하며 제외 지점에서 연속 판정을 끊었다. [평가 규약](evaluation_protocol.md) · [수동 대상 주석](../experiments/annotations/manual_subjects.json)

추적 실패는 가시 대상의 현재 관측이 연속 10프레임 이상 없을 때 한 건으로 센다. 대상 중 한 명이라도 연속 10프레임을 판정할 수 있으면 유효 사건에 포함한다. 조건별 실패율의 분모는 유효 사건 수, 분자는 그중 실패가 한 건 이상인 사건 수다. 겹침 전 연속 3프레임에서 기준 ID를 확보하고 분리 후 다른 ID가 5프레임 이상 지속되면 ID Switch로 집계한다. 겹침 외 조건에서는 같은 3·5프레임 기준의 지속 ID 변경을 별도로 집계한다. [평가 규약](evaluation_protocol.md)

거리 제한 60픽셀에서 계획한 30건 모두 추적 실패를 판정할 수 있었다. 겹침 ID Switch는 20명 중 겹침 전후에 기준 관측이 확보된 7명에서만 집계했다. 표의 `—`는 해당 조건에 그 지표를 적용하지 않았음을 뜻한다. 한 프레임에서 두 사람이 제외되면 제외 대상 프레임을 2개로 센다. 겹침에서는 5건의 ID 변경이 지속됐고, 미관측 길이는 별도의 10프레임 실패 기준에 이르지 않았다. vtest의 정지 사례 `stop-04`에서 대상은 원본 f406–448의 43프레임 동안 현재 관측과 대응되지 않았다. 이 결과는 정지 인물도 배경 차분에 의존하는 감지에서 오래 누락될 수 있음을 보여 준다. 서로 다른 장면·해상도에서 선정한 30건이므로 표의 실패율은 이 사건들에 대한 결과다. [대상별 연속 구간](../experiments/runs/event_details.json)

조명 변화 다섯 건은 Wallflower LightSwitch의 소등·점등·소등 세 건과 TimeOfDay의 점진적 밝아짐(f1810–1909)·어두워짐(f4718–4817) 두 건이다. 각 클립은 원본 4 Hz에서 100프레임, 25초다. SBMnet의 두 후보는 원 촬영 FPS와 촬영 구간 길이를 확인할 수 없어 최종 집계에서 제외했다. 같은 10프레임 기준도 vtest에서는 약 1초, CAVIAR에서는 약 0.4초, Wallflower에서는 약 2.5초를 나타낸다. [자료 출처와 프레임 범위](data_sources.md)

TimeOfDay의 두 클립에서 처음과 끝 8프레임 평균 회색조 영상 사이의 픽셀 차이 중앙값은 각각 +1.75와 −2.88이었다. 두 사건의 미관측 구간은 원본 f1851–1909와 f4759–4817이었다. 두 장면 모두 사람이 소파로 이동해 앉으므로, 이 실패에 조명 변화와 대상의 정지가 각각 얼마나 기여했는지는 분리할 수 없다. LightSwitch 급변 세 사건에서 10프레임 기준의 추적 실패는 집계되지 않았다. [원본 밝기 확인](data_sources.md) · [대상별 연속 구간](../experiments/runs/event_details.json)

## 2. ORB 특징점 매칭 성능

`box.png`를 참조로 두고 같은 사진을 회색 여백에 올린 정면, 이미지 평면 회전 30°·60°, 왼쪽 직사각형 가림 약 30%·50%를 비교했다. 최대 특징점 수 1,000, Hamming 거리의 최근접 두 후보 비율 0.75, 발견 최소 매칭 수 12를 고정했다. 매칭률은 일대일 유효 매칭 수를 참조 특징점 수로 나눈 값이다. 참조 특징점이 0개이면 매칭률은 `N/A`다. ## 3. 배경 모델링의 한계

겹침 `overlap-05`, 정지 `stop-04`, Wallflower 점등 `illumination-02`에서 동일 클립·시작 프레임·형태 필터·추적 설정을 유지하고 새 MOG2의 학습률만 바꿨다. 3개 클립을 3개 설정에서 처리한 9회, 1,800프레임이다. 각 앵커부터 클립 끝까지 후처리 전경 픽셀 비율의 최대·평균을 집계했다. 안정 구간 시작은 전경 비율이 10% 이하인 프레임이 5개 연속 나타난 첫 구간의 시작이며, 표는 앵커부터의 프레임 차이를 표시한다. 이 지표는 마스크의 활동량을 나타낸다. ## 4. 거리 기반 추적의 한계

겹침에서 두 전경이 한 윤곽선으로 합쳐지면 중심점 하나만 트래커에 전달된다. 다시 분리될 때 현재 위치에서 가장 가까운 ID를 찾으므로, 지나간 사람의 위치가 서로 바뀌면 다른 사람의 ID가 배정될 수 있다. 예를 들어 `overlap-07`의 60픽셀 실행에서는 대상 1의 ID가 14에서 17로 바뀌어 f509–513에서 유지됐고, 대상 2는 11에서 14로 바뀌어 f508–513에서 유지됐다. 이전 대상 1의 ID가 분리 뒤 다른 사람에게 연결됐다. [대상별 ID 변경 구간](../experiments/runs/event_details.json)

겹침 10건을 동일한 입력과 감지 설정으로 다시 실행하고 거리 제한만 60에서 30픽셀로 좁혔다. 316개 대상·프레임 기록에서 두 실행의 관측 박스 좌표를 대조해 일치를 확인했다. 두 실행 모두 추적 실패 0/10, ID Switch 판정 가능 인원 7명이었다. ID Switch는 5건에서 6건으로 늘었다. `overlap-06`은 60픽셀에서 ID Switch 0건이었고, 30픽셀에서는 대상 2가 ID 16에서 18로 바뀐 채 f486–491에 관측됐다. 더 좁은 거리 제한은 연결 후보를 줄여도 분리된 사람을 구별할 새로운 단서를 제공하지 못한다. [조건별 거리 비교](../experiments/runs/event_summary.csv) · [원본 프레임과 박스](../experiments/runs/event_frames.csv)

## 5. 사람이 설계한 특징의 한계

ORB는 각 특징점 근방의 방향을 구해 BRIEF 비교 패턴을 회전시킨다. SIFT 역시 특징점에 방향을 할당해 영상 평면 회전을 견디도록 설계됐다. 이번 ORB의 30°·60° 결과는 모두 발견에 성공했지만 정면보다 매칭률이 낮았다. 60°가 30°보다 낮지는 않았으므로 이 표로 각도와 성능 사이의 단조 관계를 도출할 수 없다. [OpenCV ORB 문서](https://docs.opencv.org/4.13.0/d1/d89/tutorial_py_orb.html) · [OpenCV SIFT 문서](https://docs.opencv.org/4.13.0/da/df5/tutorial_py_sift_intro.html) · [특징점 CSV](../experiments/runs/feature_conditions.csv)

50% 가림에서 유효 매칭 수가 정면의 625개에서 70개로 줄었다. 70개도 발견 임계값 12개를 넘었다. 가림이 주요 패치 자체를 없애거나 저텍스처 표면에서 구별할 코너가 부족하면, 국소 밝기 비교만으로는 매칭 후보를 확보하기 어렵다. 이번 실험은 한 참조 사진의 인위적 평면 회전과 가림이다. 실제 물체의 평면 밖 시점 변화, 저텍스처 물체 집합, SIFT의 성능은 측정하지 않았다. [통제 조건과 양성 장면](../experiments/runs/feature_metadata.json)

## 6. 학습 기반 접근을 고려할 이유

- **객체 외형을 학습하면 겹침에서 도움이 될까?** 겹침 후 중심점만으로 구별하기 어려운 두 사람의 외형을 함께 사용하면 다시 나타난 관측을 연결할 근거가 생긴다. 가림 중에는 새 외형 정보가 들어오지 않고, 외형이 비슷하거나 영상 해상도가 낮으면 재식별이 여전히 어렵다. [거리 제한 비교](../experiments/runs/event_summary.csv)
- **여러 변형을 학습하면 특징점 매칭이 개선될까?** 50% 가림에서 매칭률이 7.0%까지 떨어졌다. 가림과 시점 변화가 있는 예시로 학습한 표현은 남아 있는 여러 영역이나 형태를 함께 사용할 수 있다. 새로운 물체와 시점에서의 개선 정도는 별도 검증이 필요하다. [특징점 CSV](../experiments/runs/feature_conditions.csv)
- **환경 변화를 학습하면 배경 모델이 강건해질까?** 점등 때 전경 비율이 화면 대부분으로 치솟은 사례에서는 조명 전환을 물체 이동과 구별하는 표현이 도움이 될 수 있다. 실제 여러 조명 환경과 카메라에서 학습·검증해야 하며, 급변 적응과 정지 대상 보존을 따로 평가해야 한다. [학습률 비교](../experiments/runs/learning_rates.csv)
